# Routine Tracker Keypad
A 9-key toggle momentary control pad built for sensory-rich task initiation and habit reinforcement.

---

## Overview

The keypad functions as a physical interface for task sequencing, using tactile feedback and LEDs to mark progress.  
Each key represents a discrete task (e.g. *turn on music*, *take medication*, *brush yout teeth*).  
Internally, momentary switches are wired through **SN74HC74 dual D-type flip-flops** for edge-triggered toggling. (TBD)
